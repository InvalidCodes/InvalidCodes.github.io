# Yunfei Ge Personal Website

Static academic homepage built with HTML, CSS, and a small amount of JavaScript.

## Local Preview

```bash
cd /Users/yunfei/Intern/personal_website
python3 -m http.server 8000
```

Open `http://localhost:8000`.

## Structure

- `index.html` contains the page content.
- `assets/css/styles.css` contains layout, typography, and responsive rules.
- `assets/js/main.js` controls the mobile menu and active navigation state.
- `assets/images/` contains optimized WebP profile photos and favicon.
The original `IMG_8990.JPG` is retained as source material and is not loaded by the website.
